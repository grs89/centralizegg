Virtualización (KVM & Proxmox)

🚀 Cómo Iniciar

  1. Navega al menú Virtualización > KVM.
  2. Haz clic en el botón de configuración .
  3. Añade tu servidor proporcionando la IP, Usuario y Clave SSH.

📋 Requerimientos Mínimos

  • Sistema Operativo: Linux con Libvirt/QEMU instalado.
  • Acceso SSH: Clave pública configurada (`authorized_keys`).
  • Permisos: El usuario SSH debe pertenecer al grupo `libvirt` o tener acceso rw al socket `/var/run/libvirt/libvirt-sock`.
  • Guest Agent (Opcional): Instalar `qemu-guest-agent` en las VMs para ver IPs y nombres de SO.
