Virtualización (KVM & Proxmox)

🚀 Cómo Iniciar

  1. Navega al menú Virtualización > KVM.
  2. Haz clic en el botón de configuración .
  3. Añade tu servidor proporcionando la IP, Usuario y Clave SSH.

📋 Requerimientos Mínimos

  • Sistema Operativo: Linux con Libvirt/QEMU instalado.
  • Acceso SSH: Clave pública configurada (`authorized_keys`).
  • Permisos: El usuario SSH debe pertenecer al grupo `libvirt` o tener acceso rw al socket `/var/run/libvirt/libvirt-sock`.
  • Guest Agent (Opcional): Instalar `qemu-guest-agent` en las VMs para ver IPs y nombres de SO.

✨ Características Visuales

  • Layout de 2 Columnas: Información del host organizada en "Sistema y Red" (Izquierda) y "Almacenamiento" (Derecha).
  • Gráficos de Torta (Donut Charts): Visualización elegante del uso de disco en el host.
  • Monitoreo de Bridges: Estado y tráfico en tiempo real para interfaces de puente (`br0`, `virbr0`) ubicado en la columna izquierda del layout de dos columnas.
  • Sparklines: Gráficos de línea minimalistas para visualizar la actividad de red reciente.
  • Historial Global Enriquecido: Métricas históricas de CPU, Memoria, Red (con umbrales de velocidad de interfaz) y Disco para cada host KVM.
  • Logs del Host en Tiempo Real: Terminal integrada en Historial Global para visualizar logs del sistema (journalctl) vía SSH.
  • Alertas OOM: Notificaciones visuales inmediatas si el "Out of Memory Killer" detiene procesos.
