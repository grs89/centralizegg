<div class="doc-content"> <h3><i class="fa-solid fa-microchip"></i> Virtualización (KVM & Proxmox)</h3> <div class="doc-section"> <h4>🚀 Cómo Iniciar</h4> <ol> <li>Navega al menú <strong>Virtualización > KVM</strong>.</li> <li>Haz clic en el botón de configuración <i class="fa-solid fa-gear"></i>.</li> <li>Añade tu servidor proporcionando la IP, Usuario y Clave SSH.</li> </ol> </div> <div class="doc-section"> <h4>📋 Requerimientos Mínimos</h4> <ul> <li><strong>Sistema Operativo:</strong> Linux con Libvirt/QEMU instalado.</li> <li><strong>Acceso SSH:</strong> Clave pública configurada (`authorized_keys`).</li> <li><strong>Permisos:</strong> El usuario SSH debe pertenecer al grupo `libvirt` o tener acceso rw al socket `/var/run/libvirt/libvirt-sock`.</li> <li><strong>Guest Agent (Opcional):</strong> Instalar `qemu-guest-agent` en las VMs para ver IPs y nombres de SO.</li> </ul> </div> <div class="doc-section"> <h4>✨ Características Visuales</h4> <ul> <li><strong>Layout de 2 Columnas:</strong> Información del host organizada en "Sistema y Red" (Izquierda) y "Almacenamiento" (Derecha).</li> <li><strong>Gráficos de Torta (Donut Charts):</strong> Visualización elegante del uso de disco en el host. </li> <li><strong>Monitoreo de Bridges:</strong> Estado y tráfico en tiempo real para interfaces de puente (`br0`, `virbr0`) ubicado en la columna izquierda del layout de dos columnas.</li> <li><strong>Sparklines:</strong> Gráficos de línea minimalistas para visualizar la actividad de red reciente.</li> <li><strong>Historial Global Enriquecido:</strong> Métricas históricas de CPU, Memoria, Red (con umbrales de velocidad de interfaz) y Disco para cada host KVM.</li> <li><strong>Logs del Host en Tiempo Real:</strong> Terminal integrada en Historial Global para visualizar logs del sistema (<code>journalctl</code>) vía SSH.</li> <li><strong>Alertas OOM:</strong> Notificaciones visuales inmediatas si el "Out of Memory Killer" detiene procesos.</li> </ul> </div> </div>
