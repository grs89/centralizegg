Firewall (pfSense)

🚀 Cómo Iniciar

  1. Ve al menú Firewall > pfSense.
  2. Abre la configuración .
  3. Registra tu firewall con credenciales SSH (Admin o usuario con privilegios).

📋 Requerimientos Mínimos

  • Versión: pfSense CE 2.6+ o Plus 22.01+.
  • SSH Habilitado: Activo desde System > Advanced > Admin Access.
  • Permisos de Usuario: Acceso a shell (`/bin/sh` o `/bin/tcsh`) y ejecución de: `top`, `sysctl`, `netstat`, `pfctl`.
  • Gateway Monitoring: dpinger debe estar activo para ver latencia y pérdida de paquetes.
