<div class="doc-content"> <h3><i class="fa-solid fa-shield-halved"></i> Firewall (pfSense)</h3> <div class="doc-section"> <h4>🚀 Cómo Iniciar</h4> <ol> <li>Ve al menú <strong>Firewall > pfSense</strong>.</li> <li>Abre la configuración <i class="fa-solid fa-gear"></i>.</li> <li>Registra tu firewall con credenciales SSH (Admin o usuario con privilegios).</li> </ol> </div> <div class="doc-section"> <h4>📋 Requerimientos Mínimos</h4> <ul> <li><strong>Versión:</strong> pfSense CE 2.6+ o Plus 22.01+.</li> <li><strong>SSH Habilitado:</strong> Activo desde System > Advanced > Admin Access.</li> <li><strong>Permisos de Usuario:</strong> Acceso a shell (`/bin/sh` o `/bin/tcsh`) y ejecución de: `top`, `sysctl`, `netstat`, `pfctl`.</li> <li><strong>Gateway Monitoring:</strong> dpinger debe estar activo para ver latencia y pérdida de paquetes. </li> </ul> </div> <div class="doc-section"> <h4>✨ Características Principales</h4> <ul> <li><strong>Mapa de Tráfico:</strong> Visualización en tiempo real de conexiones externas (IPs geolocalizadas) y flujo de datos.</li> <li><strong>Monitoreo de Gateways:</strong> Estado detallado, latencia (ms) y pérdida de paquetes (%) por cada puerta de enlace.</li> <li><strong>Tablas de Estado:</strong> Seguimiento del tamaño y límite de la tabla de estados del firewall (PF states).</li> <li><strong>Interfaces Avanzadas:</strong> Gráficos sparkline para cada interfaz, incluyendo errores y descartes de paquetes.</li> <li><strong>Historial Global:</strong> Métricas históricas de CPU, Memoria, Red (con umbrales de velocidad de interfaz) y Disco para monitoreo a largo plazo.</li> <li><strong>Logs del Host en Tiempo Real:</strong> Visualización de logs del sistema (<code>clog</code>) directamente desde la interfaz de Historial Global.</li> </ul> </div> </div>
