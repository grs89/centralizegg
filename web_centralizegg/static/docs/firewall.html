Firewall (pfSense)

🚀 Cómo Iniciar

  1. Ve al menú Firewall > pfSense.
  2. Abre la configuración .
  3. Registra tu firewall con credenciales SSH (Admin o usuario con privilegios).

📋 Requerimientos Mínimos

  • Versión: pfSense CE 2.6+ o Plus 22.01+.
  • SSH Habilitado: Activo desde System > Advanced > Admin Access.
  • Permisos de Usuario: Acceso a shell (`/bin/sh` o `/bin/tcsh`) y ejecución de: `top`, `sysctl`, `netstat`, `pfctl`.
  • Gateway Monitoring: dpinger debe estar activo para ver latencia y pérdida de paquetes.

✨ Características Principales

  • Mapa de Tráfico: Visualización en tiempo real de conexiones externas (IPs geolocalizadas) y flujo de datos.
  • Monitoreo de Gateways: Estado detallado, latencia (ms) y pérdida de paquetes (%) por cada puerta de enlace.
  • Tablas de Estado: Seguimiento del tamaño y límite de la tabla de estados del firewall (PF states).
  • Interfaces Avanzadas: Gráficos sparkline para cada interfaz, incluyendo errores y descartes de paquetes.
  • Historial Global: Métricas históricas de CPU, Memoria, Red (con umbrales de velocidad de interfaz) y Disco para monitoreo a largo plazo.
  • Logs del Host en Tiempo Real: Visualización de logs del sistema (clog) directamente desde la interfaz de Historial Global.
