Backend Performance Optimizations

This page summarizes the recent performance improvements applied to the Centralizegg backend.

  • Database connection pool: SetMaxOpenConns(25) and SetMaxIdleConns(25) to reduce connection latency.
  • HTTP server timeouts: ReadTimeout, WriteTimeout set to 15 seconds and IdleTimeout set to 60 seconds for better resilience under load.
  • GZIP compression: Using gzip.BestSpeed to minimize CPU overhead while compressing API responses.
  • Persistent SSH connections: Reusing SSH sessions for collector tasks to avoid repeated handshakes.
  • Goroutine pool: Controlled concurrency for background collectors to prevent excessive goroutine creation.
  • SQL query optimizations: Refactored queries for faster data retrieval.

These changes are reflected in the source code (main.go, postgres.go) and documented in the project README files.
