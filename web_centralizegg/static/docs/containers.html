Contenedores (Docker & Podman)

🚀 Cómo Iniciar

  1. Accede a Contenedores > Docker.
  2. Configura tu host remoto proporcionando la IP y credenciales SSH.
  3. Centralizegg escaneará automáticamente el servicio y todos los contenedores activos.

📋 Requerimientos Mínimos

  • Docker Engine: API accesible vía SSH o Socket Unix local.
  • Podman: Servicio podman.socket activo (systemd).
  • GPU Monitoring: Drivers NVIDIA y nvidia-smi instalados.
  • Permisos: Usuario con permisos de ejecución de comandos Docker y herramientas de sistema.

✨ Características Principales

  • Topología de Red: Mapa interactivo animado que muestra la relación entre redes, contenedores e Internet.
  • Monitoreo de GPU: Visualización de carga, temperatura y uso de VRAM para aceleración por hardware.
  • Escaneo de CVE: Integración con docker scout para detectar vulnerabilidades críticas en imágenes.
  • Almacenamiento Detallado: Monitoreo de uso de `/var/lib/docker`, inodos y tamaños de volúmenes individuales.
  • Logs en Tiempo Real: Seguimiento del tamaño de logs y estado OOM (Out of Memory) por contenedor.
