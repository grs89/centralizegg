Contenedores (Docker & Podman)

🚀 Cómo Iniciar

  1. Accede a Contenedores > Docker.
  2. Conecta tu host Docker remoto.
  3. Centralizegg escaneará imágenes y contenedores activos.

📋 Requerimientos Mínimos

  • Docker Engine: API habilitada (TCP Socket) o accesible vía túnel SSH.
  • Podman: Servicio podman.socket activo (systemd).
  • Permisos: Usuario miembro del grupo `docker` en el host remoto.
