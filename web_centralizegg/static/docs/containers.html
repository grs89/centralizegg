<div class="doc-content"> <h3><i class="fa-solid fa-box"></i> Contenedores (Docker & Podman)</h3> <div class="doc-section"> <h4>🚀 Cómo Iniciar</h4> <ol> <li>Accede a <strong>Contenedores > Docker</strong>.</li> <li>Configura tu host remoto proporcionando la IP y credenciales SSH.</li> <li>Centralizegg escaneará automáticamente el servicio y todos los contenedores activos.</li> </ol> </div> <div class="doc-section"> <h4>📋 Requerimientos Mínimos</h4> <ul> <li><strong>Docker Engine:</strong> API accesible vía SSH o Socket Unix local.</li> <li><strong>Podman:</strong> Servicio <code>podman.socket</code> activo (systemd).</li> <li><strong>GPU Monitoring:</strong> Drivers NVIDIA y <code>nvidia-smi</code> instalados.</li> <li><strong>Permisos:</strong> Usuario con permisos de ejecución de comandos Docker y herramientas de sistema.</li> </ul> </div> <div class="doc-section"> <h4>✨ Características Principales</h4> <ul> <li><strong>Topología de Red:</strong> Mapa interactivo animado que muestra la relación entre redes, contenedores e Internet.</li> <li><strong>Monitoreo de GPU:</strong> Visualización de carga, temperatura y uso de VRAM para aceleración por hardware.</li> <li><strong>Escaneo de CVE:</strong> Integración con <code>docker scout</code> para detectar vulnerabilidades críticas en imágenes.</li> <li><strong>Almacenamiento Detallado:</strong> Monitoreo de uso de `/var/lib/docker`, inodos y tamaños de volúmenes individuales.</li> <li><strong>Historial Global de Host:</strong> Métricas históricas de rendimiento del servidor Docker/Podman con gráficos de CPU, Memoria, Red y Almacenamiento.</li> <li><strong>Logs del Host en Tiempo Real:</strong> Terminal integrada para visualizar logs del sistema (<code>journalctl</code>) del servidor de contenedores.</li> <li><strong>Logs de Contenedores:</strong> Seguimiento del tamaño de logs y estado OOM (Out of Memory) por contenedor.</li> </ul> </div> </div>
