Almacenamiento (NAS & Ceph)

🚀 Cómo Iniciar

  1. Selecciona Almacenamiento > NAS / Ceph.
  2. Configura los endpoints de tu clúster o servidor de archivos.
  3. (Próximamente) La integración se realizará vía API REST (Ceph Mgr) o SSH (ZFS/LVM).

📋 Requerimientos Mínimos

  • Ceph: Acceso al Dashboard API (Manager Module) o usuario SSH con acceso a `ceph status`.
  • NAS: Soporte para consultas SNMP v2c/v3 o agente SSH Linux estándar.
  • Red: Conectividad a los puertos de gestión (8443, 22).
