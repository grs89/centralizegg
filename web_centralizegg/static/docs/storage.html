Almacenamiento (NAS Linux)

🚀 Cómo Iniciar

  1. Selecciona Almacenamiento > NAS.
  2. Haz clic en Configuración .
  3. Agrega tu servidor Linux/NAS proporcionando la IP, Usuario y Clave SSH.

📋 Requerimientos Mínimos

  • Sistema Operativo: Linux estándar (Debian, Ubuntu, CentOS, TrueNAS Scale, etc.).
  • Acceso SSH: Usuario con permisos de lectura.
  • Comandos Requeridos: `df`, `lsblk`, `free`, `uptime`, `hostnamectl`, `iostat`.
  • Sin Agentes: No requiere instalar software adicional en el NAS.

✨ Características Principales

  • Visualización de Volúmenes: Gráficos de barra para uso de espacio en todos los puntos de montaje.
  • Inventario de Discos: Lista detallada de discos físicos (`lsblk`) con modelo, serie y tamaño.
  • Métricas de I/O por Disco: Historial de tasas de lectura/escritura para cada disco físico individual en la herramienta de Historial Global.
  • Logs del Host: Terminal en vivo integrada en Historial Global para ver logs del sistema (journalctl) del servidor NAS.
  • Métricas de Sistema: CPU, RAM y Uptime del servidor de almacenamiento.
  • Alertas de Espacio: Indicadores visuales (Ámbar/Rojo) cuando el uso de disco supera el 80% o 90%.
